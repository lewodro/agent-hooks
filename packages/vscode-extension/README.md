# Agent Hooks — Solana Lending Hooks (VS Code)

Visualise Compositions as knot diagrams, run simulations from your editor, and print a deploy plan.

## Commands

- `Agent Hooks: Open Hook Designer` — opens a webview with the six standard hooks rendered as ropes on a workbench.
- `Agent Hooks: Simulate Current Composition` — runs the deterministic simulator and prints the report to the Agent Hooks output channel.
- `Agent Hooks: Show Deploy Plan` — prints the Anchor deploy steps for the configured cluster.

## Settings

- `agent-hooks.defaultPool` — default pool label for simulations.
- `agent-hooks.cluster` — `localnet` / `devnet` / `mainnet` (used only by the deploy plan).
